## 三、名词解释题

### 1. 数据结构的基本概念

- **逻辑结构**：描述数据元素间的抽象关系（如线性、树形），**与计算机无关**；存储结构和物理结构依赖于具体实现。

### 2. 线性表相关

- **顺序表**：顺序表的一个存储结点存储线性表的一个结点的内容，即数据元素，所有存储结点按照相应数据元素间的逻辑关系决定的次序依次排列。
- **链式存储结构**：为了正确表示结点间的逻辑关系，在存储每个结点值的同时，还必须存储指示其直接后继结点的地址（或位置），称为指针（pointer）或链（link），这两部分组成了链表中的结点结构。
- **双向链表（Double Linked List）**：指的是在保存结点（node）数据的同时，构成链表的每个结点中设立两个指针域：一个指向其直接前趋的指针域 `prior`，一个指向其直接后继的指针域 `next`。这样形成的链表中有两个方向不同的链，故称为双向链表。

### 3. 树和二叉树

- **二叉树**：二叉树（binary tree）是结点（node）的一个有限集合，这个集合或者为空，或者是由一个根结点以及两棵互不相交的、分别称为这个根的左子树和右子树的二叉树组成。左子树和右子树的根分别称为此二叉树根结点的左孩子结点和右孩子结点。
- **树的度**：树结构中，结点所拥有的子树的棵数称为结点的度。树中结点度的最大值称为树的度。

### 4. 图

- **连通图**：如果无向图 G 中任意一个顶点到其他任意顶点都至少存在一条路径，也就是说，图中任意两个顶点都是连通的，则称图 G 为连通图（connected graph）。
- **图的邻接表**：图的一种链式存储结构。在邻接表中，对图中每个顶点建立一个单链表，n 个顶点就要建 n 个链表；无向图中，单链表中的结点表示依附于顶点 vᵢ 的边，对于有向图，是以顶点 vᵢ 为尾的弧。

### 5. 排序

- **冒泡排序**：先将第一个和第二个键值比较交换，然后比较第二个和第三个键值交换，以此类推，直到第 n 个和第 n-1 个记录比较交换，这称为一趟起泡。每趟将键值最大的记录换到最后。重复以上过程，每次移动都向最终目标前进，直至没有记录需要交换为止。
- **内部排序（内排序）**：当待排序的数据量不大，全部数据都可以放入内存，排序操作也完全在内存中进行时，相应的排序称为内部排序或内排序。

## 四、算法实现题

### 1. 单链表第 i 个位置插入结点

**题目**：阅读下面的单链表表第 i 位置上插入一个以 x 为值的新结点的算法，请在空缺处填入合适的内容，使其成为一个完整的算法。

```c
void ins_lklist(lklist head, int i) {
    p = find_lklist(head, i - 1);
    if (p == NULL)
        error("不存在第i个位置");
    else {
        s = malloc(size); s->data = x;
        (1) ________________________;
        (2) ________________________;
    }
}
```

**答（完善）**：

```c
(1) s->next = p->next;
(2) p->next = s;
```

> 注意两句顺序不能颠倒：必须先让新结点接上后继链，再让前驱结点指向新结点。

### 2. 求二叉查找树中的最大关键字

**题目**：设二叉查找树中保存的是整数。编写程序，返回一棵二叉查找树上最大关键字。
提示：二叉查找树中最大关键字位于树的"右下角"，即从根开始，沿右孩子指针向下查找，其右孩子指针为空的结点中保存的是二叉查找树中的最大值。

**答：程序实现如下所示。**

```c
int MaxOfBstSearch(BstTree t) {
    // 若树为空，则返回 NA
    BstNode *temp = t;
    if (t == NULL)
        return NA;
    while (temp->right != NULL) {
        temp = temp->right;
    }
    return temp->data;
}
```

> 原投影写成 `while(temp->right!=NULL);`（句尾多一个分号）会造成死循环，此处已按题意改正。

### 4. 由前序和中序遍历序列画出二叉树

**题目**：已知二叉树的遍历前序：ABDEGCFH，和中序：DBGEAFHC，画出二叉树。

**答案**：前序首元素 A 为根；中序中以 A 划分，左子树结点集合 {B, D, E, G}，右子树结点集合 {C, F, H}。还原结果如下：

```
              A
            /   \
          B       C
        /   \    /  
       D     E  F    
            /    \
           G      H
```

括号表示法：`A( B( D, E( G ) ), C( F( , H ), — ) )`

即：B 的左孩子 D、右孩子 E；E 的左孩子 G；C 的左孩子 F、右孩子为空；F 的右孩子 H。

自检：前序 A B D E G C F H ✅；中序 D B G E A F H C ✅。
