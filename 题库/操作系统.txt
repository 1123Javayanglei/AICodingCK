练习三（解答题）

1. 说明处理机的内核态和用户态模式，使用双重模式的好处是什么？
参考答案：
  处理机至少需要两种单独运行模式：用户态和内核态。当计算机执行用户程序时，系统处于用户态；当用户通过系统调用请求操作系统服务时，系统转向执行系统程序，切换到内核态。
  双重模式执行提供了保护手段，以防止操作系统和用户程序受到错误用户程序的影响。

2. 操作系统的异步特征指什么？其产生的原因是什么？
参考答案：
  操作系统的异步特征：在多道程序环境下，允许多个程序并发执行，但程序是以人们不可预知的速度向前推进，即程序的执行具有异步特征。
  其原因是由于资源等因素的限制，所以程序是以"走走停停"的方式运行。

3. 说明进程和线程的基本概念，其主要区别是什么？
参考答案：
  进程：进程是一个程序的执行过程，是系统进行资源分配和调度一个独立单位。
  线程：线程是进程内的一个执行单元或一个可调度实体。
  主要区别：
  1. 进程可以拥有资源，作为系统中独立拥有资源的一个基本单位，而线程几乎不拥有资源，仅有一些确保自己独立运行的必要资源。
  2. 同一进程中的不同线程之间的独立性，比不同进程之间的独立性要低得多。
  3. 线程的切换代价远低于进程的切换。

4. 说明抢占式调度与非抢占式进程调度的区别。为什么现代操作系统广泛采用抢占式调度？
参考答案：
  在采用抢占式调度方式时，允许调度程序根据某种原则暂停某个正在执行的进程，并将已经分配给该进程的处理机重新分配给另一个进程。
  采用非抢占式调度方式时，一旦把处理机分配给某个进程，就不能因为时钟中断或其他原因去抢占该进程的处理机，直至该进程完成或发生某事件而被阻塞时，才能把分配给该进程的处理机分配给其他进程。
  现代操作系统广泛采用抢占式调度：对于批处理系统，可以防止一个长进程长时间占用处理机，确保能为所有进程提供更加公平的服务。在分时系统中，采用抢占式调度才有可能实现人机交互。在实时系统中，才能满足实时任务的需求。

5. 进程控制块 PCB 存储了进程的具体信息，主要包括哪些方面的信息？
参考答案：
  进程控制块 PCB 存储了进程的所有描述信息，实现对进程的控制。主要包括：
  1. 进程标识符，包括外部标识符和内部标识符；
  2. 处理机状态，各种寄存器的内容；
  3. 进程调度信息，包括进程状态、优先级、调度信息、事件情况；
  4. 进程控制信息，程序和数据地址、进程同步和通信机制、资源清单等。

6. 什么是进程同步？主要任务是什么？
参考答案：
  操作系统在异步环境下的一组并发进程因直接制约而互相发送消息、互相合作、互相等待，使得各个进程按照一定的速度执行的过程，称为进程同步。
  进程同步的主要任务是：在执行次序上对多个协作进程进行协调，使并发的各个协作进程能够按照一定的规则（时序）共享系统资源，并能很好地相互合作，从而使程序的执行具有可再现性。

7. 计算机系统存储组织一般包含哪四个层次？如何配置这些层次来实现较高的性价比？
参考答案：
  计算机系统存储组织一般包含四层：从高到低为 CPU 寄存器、高速缓冲、主存储器（内存）、辅助存储器（外存）。
  配置方法：层次越高，速度越快，价格也越高，则配置的存储容量较小；层次越低，速度越慢，价格也越低，则配置的存储容量较大，实现较高性价比。

8. 虚拟存储管理系统中程序执行的"局部性"指什么？包含哪些方面？请说明其含义。
参考答案：
  虚拟存储管理系统中程序执行的"局部性"是指在一段较短的时间内，程序的执行仅局限于某个部分，它所访问的存储空间也局限于某个区域。
  主要包含两个方面：
  1. 时间局限性。如果程序中某条指令被执行，则不久后该指令可能会被再次执行；如果某数据被访问过了，则不久后该数据可能会被再次访问。
  2. 空间局限性。一旦程序访问了某个存储单元，不久之后，附近的存储单元也将会被访问，即程序在一段时间之内所访问的地址可能集中在一定范围之内。

9. 文件系统使用访问矩阵实现文件保护时，其行和列、矩阵中的元素分别代表什么？
参考答案：
  文件保护的访问矩阵中，行代表域，列代表对象。常见的情况是，每个用户是一个域，而对象是文件。
  矩阵中对应行和列交叉点的元素 A(i, j) 表示第 i 用户对第 j 文件的操作集。

10. 文件的物理结构有连续结构、链接结构和索引结构，请分别简述其优点和缺点。
参考答案：
  文件的物理结构直接与外存储器的组织方式有关。
  连续结构：必须为每个文件分配一个连续的磁盘空间，所形成的物理结构是顺序文件结构。
  - 主要优点：顺序访问容易，速度快。
  - 缺点：要求为一个文件分配连续的存储空间，必须事先知道文件长度，不能灵活插入和删除记录，不适合存储动态增长的文件。
  链接结构：可为文件分配多个不连续的盘块，再通过每个盘块上的链接指针，将属于同一个文件的多个离散的盘块链接成一个链表，形成链接文件。
  - 主要优点：消除了外部碎片，提高外存的利用率；便于插入、删除和修改记录；能适应文件的动态增长。
  - 缺点：不能支持高效的直接存取，文件分配表 FAT 须占用较大内存空间。
  索引结构：为每个文件分配一个索引块（表），把分配给该文件的所有盘块号都记录在该索引块中。建立一个文件时，只需在所建立的目录项中写入指向该索引块的指针。
  - 主要优点：支持直接访问，不会产生外部碎片。
  - 缺点：对于中小型文件，索引块的利用率比较低。

12. 计算机 I/O 系统包含哪三个层次？其主要功能？
参考答案：
  计算机 I/O 系统包含三个层次：
  1. 中断处理程序，处于 I/O 系统最低层，直接与硬件进行交互。
  2. 设备驱动程序，处于 I/O 系统次低层，是进程和设备控制器之间的通信程序，将上层的抽象 I/O 请求转换为针对 I/O 设备的具体命令和参数，装入设备控制器的相应寄存器；或进行相反的转换。
  3. 与设备无关的 I/O 软件，I/O 软件独立于具体使用的物理设备，提高了 I/O 系统的适应性和扩展性，便于设备增加或更新。

1. 单 CPU 和两台输入/输出设备（S1，S2）的多道程序设计环境下，三个作业（J1，J2，J3）对 CPU 和输入/输出设备的使用顺序和时间如下：
  - J1：S2（30ms），CPU（10ms），S1（30ms），CPU（10ms），S2（20ms）
  - J2：S1（20ms），CPU（20ms），S2（40ms）
  - J3：CPU（30ms），S1（20ms），CPU（10ms），S1（10ms）
  若同时投入三个作业 J1，J2，J3 运行，CPU、S1、S2 都能并行工作。J1 优先级最高，J3 优先级最低，优先级高的作业可以抢占优先级低的作业的 CPU，但不能抢占 S1 和 S2。

  （2）从投入到完成的 CPU 利用率？
  （3）I/O 设备的利用率？

  先画出各个作业运行过程，即可得到以下答案。
  1. 根据三个作业的运行情况分析，J1、J2、J3 从投入到完成分别需要的时间是 110ms，90ms，110ms。
  2. 从作业投入到完成的 CPU 利用率：（20+10×6）/110 = 72.7%
  3. 设备 S1 的利用率：（20+30+20+10）/110 = 72.7%；设备 S2 的利用率：（30+40+20）/110 = 81.8%

2. 在一个分页存储管理系统中，逻辑地址长度 16 位，页面大小 4KB。现有逻辑地址 2F6AH，且第 0、1、2 页依次存放在物理块 5、10、11 中，问相应的物理地址是多少？
参考答案：

4. 有 n 个进程（P1、P2、…、Pn）向容量为 M 的缓冲区写数据，每个进程一次写一个数据；当缓冲区写满时，另一个读进程 Pr 一次将 M 个数据全部读完，如此反复。请用信号量解决这些进程的同步互斥问题。
参考答案：
  用信号量 empty 表示缓冲区还能写几个, full 表示已经写了几个, mutex 保证读写互斥:
  ```c
  Semaphore empty = M, full = 0, mutex = 1;
  Main()
  cobegin {
      Pi()            /* i = 1, …, n */
      while (1) {
          wait (empty);
          wait (mutex);
          put_data();
          signal (mutex);
          signal (full);
      }
      Pr()
      while (1) {
          for (i = 0; i < M; i++)
              wait (full);
          wait (mutex);
          get_all_data();
          for (i = 0; i < M; i++)
              signal (empty);
          signal (mutex);
      }
  } coend
  ```
