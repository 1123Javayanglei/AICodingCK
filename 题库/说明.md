# 题库目录

把科目的题目 txt 放在这里, 文件名就是科目名, 然后运行:

```
node scripts/build-questions.js
```

例如放一个 `数据结构.txt`, 重新生成后首页就会出现"数据结构"标签页,
它的错题本和成绩记录和英语完全分开。

不想让它单独占一个标签页 (比如阅读理解其实是英语的一个题型), 就用 `extra` 把它
并进已有科目, 见下面"并进已有科目"。

## txt 格式

```
练习一（原书第 1–20 题）
1. 栈的操作特点是 ____。
A. 先进先出        B. 后进先出        C. 随机存取        D. 顺序存取
答案：B
2. 下一题...
```

- 分节标题以 `练习` 开头, 括号里的内容是可选的说明
- 选项写在一行, 用 3 个以上空格隔开; 也可以每个选项各占一行。**个数按题型来**:
  一般四个, 单句翻译是三个 (`TYPE_RULES` 里题型没写 `options` 就是 4)。个数不对
  解析器会报错, 不会把两个选项粘成一个
- 答案行固定写 `答案：X`(全角冒号)
- 题号和选项字母后要有 `.` 加空格
- 以 `#` 开头的整行都是注释, 解析器直接跳过 (所以答案行后面不能跟行内注释)
- 不属于以上任何一类的散行会**报错**, 不会悄悄粘到上一题题干的尾巴上

## 折行

行首空两格(或更多)表示**续行** —— 这一行接在上一行后面, 不新起一段。
短文正文和翻译原文是一段一行, 太长就折开, 别让一行拖到几百个字符:

```
There are many theories about the beginning of drama in ancient Greece. The one most widely accepted
  today is based on the assumption that drama evolved from ritual. The argument for this view goes
  as follows. ...
```

上面这段在页面上仍然是**一个自然段** —— 缩进只是给编辑器看的。折行时只在原有的
空格处断, 解析器按空格拼回去, 拼出来的文字和没折行时逐字节相同。

懒得手折可以跑(会把整个文件重新折成 ~100 列; 中文没有空格可断, 断不动就保持原样):

```
node scripts/rewrap-bank.js 题库/阅读理解.txt
```

题干、参考译文同样可以用缩进续行; 缩进的行前面空空如也(没有可接的内容)时解析器
会报错, 不会瞎猜。

## 分值

分值默认**按题型给**, 不用在 txt 里配 (配在 `scripts/build-questions.js` 的
`TYPE_RULES` 里): 单选题 1 分, 单句翻译 2 分, 阅读理解的选择题 2 分, 翻译题 5 分,
填空题 1 分, 名词解释题 6 分。

要改整个科目的分值, 也可以在文件任意位置(习惯放开头)写一行:

```
# 设置: 单选每题 2 分, 填空每题 2 分, 名词解释每题 6 分, 随机抽 10 题, 不加入模拟考试
```

- `单选每题 N 分` 这样**按题型给分**最省事: 写 `单选` / `填空` / `名词解释`,
  分别管这三种题型 (`选择每题 N 分` 是老的粗写法, 会盖住该文件里所有**非翻译题**,
  两个都写则按题型的优先)
- `翻译每题 N 分` 管翻译题
- `随机抽 N 题` 定首页"随机抽取 N 题"那个勾选框抽几道 (不写默认 20);
  题库里的单选题不比 N 多就不摆这个勾选框
- `不加入模拟考试` 会让首页不摆"模拟考试"入口, 只留练习模式
  (分值定下来后别再改, 否则首页、成绩单和历史记录的满分对不上)

题型分值本身就是靠 `exam` 标记决定谁进模拟考试的: 只有单选题能进, 阅读理解、
单句翻译、多选 / 判断 / 填空都不进 —— 它们走首页各自的勾选框, 见下面
"模拟考试里的阅读理解"、"模拟考试里的单句翻译"和"模拟考试里的填空题 / 名词解释题"。

## 阅读理解的短文体

一篇短文就是一个题组, 用 `【A】` `【B】` `【C】` 标记, 标记下面到第一道题之间
的行全是短文正文, **一个自然段一行**(长了就在段落中间折行, 续行缩进两格, 见上面
"折行")。**每篇的题号都从 1 开始**, 解析器会把篇号编进题目 id
(`r1-B-3`), 所以同一个练习里三篇都叫"第 1 题"也不会串。

```
练习一（基础版 UNIT 5 SCIENCE）
【A】
The electric eel is a strange fish.
It lives in the rivers of South America.
1. What is the electric eel?
A. A fish        B. A bird        C. A snake        D. A plant
答案：A
...
```

书上用方括号 `[ ]` 框出来要翻译的那一段, 这里原样保留 —— 前端会把方括号里的
内容高亮出来, 让人一眼看清"要翻的是哪一段"。

练习时**一篇短文一页**: 短文和它名下的题目摆在同一页, 一道一道即时判分, 点
"下一篇"翻到下一篇短文 (本页没做的题按答错收尾), 最后一篇点"完成练习"结算。
所以一篇短文里的题目**在 txt 里必须连着写**, 别把两篇的题交错着排。

## 模拟考试里的阅读理解

首页考试卡片上有个"加入阅读理解"勾选框 (题库里有普通篇和带翻译的篇各 2 篇以上
才摆出来), 勾上之后每场随机抽 **4 篇** —— 2 篇普通篇 + 2 篇带翻译题的篇, 整篇
名下的题目全进卷。按现在的题库就是 20 道选择 × 2 分 + 2 道翻译 × 5 分 = 50 分
(满分和题数是从题库里读的, 换了题库自动跟着变)。

- 考试里短文和它的题目**一页一篇**, 单选仍是**一题一页**, 顶上的答题卡按页跳
  (短文那格会写"短文 A · 3/6"告诉这页做了几道)
- 翻译题在考试里和练习一样**当场自评**, 判完才给参考译文; 没自评的交卷时算"未答"
- 交卷时没答的题算未答 (不像练习翻篇那样强制收尾), 提交前会提示还剩几题
- 阅读理解的选项同样跟着"选项位置随机打乱"走

## 模拟考试里的单句翻译

单句翻译就是**三选项的选择题** (`A/B/C`), 分节标题里写 `单句翻译` 就识别。
题型表里它是 `exam: false`, 单考不进模拟考试, 走首页考试卡片上的"加入单句翻译"
勾选框 (题库里够 5 道才摆出来), 勾上之后每场随机抽 **5 道**, 按现在的题库就是
5 × 2 分 = 10 分 (题数和满分从题库里读, 换了题库自动跟着变)。

- 单句翻译**没有短文**, 所以考试里是**一题一页**, 混在单选题后面、短文页前面
- 单选一题一页时它跟着逐题翻; 勾了阅读变一篇一页混排时, 它自动变成单独一页
- 选项同样跟着"选项位置随机打乱"走 (错题本里记的仍是题库里的原始下标)
- 练习模式里它单独一张题型卡, 逐题即时判分, 零散的分节也能单练

## 模拟考试里的填空题 / 名词解释题

这两种题题型表里也是 `exam: false`, 不混在单选题里考, 走首页考试卡片上各自的
勾选框 (`加入填空题 (随机 10 道, 20 分)` / `加入名词解释 (随机 5 道, 30 分)`,
**题库里够 10 道 / 5 道才摆出来**, 默认都不勾):

- 勾上之后每场随机抽 10 道填空 + 5 道名词解释, 排在单选题后面 (填空在前)
- 答题流程和练习一样**当场自评**, 判完才给参考答案; 没自评的交卷时算"未答"
  (开了"填空自动判分"的科目例外: 考试里就是**交卷时统一比对**, 见上面
  "填空题自动判分")
- 被设置点名成"直接看答案"的题型不在这儿 —— 不用作答的题没法判分, 所以整个不进
  考试, 勾选框自动不摆 (数据结构的名词解释就是这种, 见上面"解答题 / 看答案的题")
- 分值是题库里的每题分 × 抽几道, 钩选框上的数字和首页说明都从题库读
- 成绩单照旧按题型拆对/错/未答 (这几行会一起出现)

## 翻译题

翻译题的题干固定以 `把上面用方括号` 开头(解析器靠这句话认题型), 下面写原文,
再下面写 `参考译文：`。**没有选项, 也不写 `答案：`**。

```
6. 把上面用方括号 [ ] 标出的那一段译成中文。
The electric eel can produce electricity.
参考译文：电鳗能产生电。
```

翻译题没有标准答案可判, 所以练习时由做题的人自己判对错(判完才显示参考译文),
判对得满分, 判错进错题本。参考译文请认真写 —— 它就是唯一的对照标准。

## 填空 / 名词解释题 (文字题)

这两种题**没有选项**, 答案写在 `参考答案：` 行里。默认由做题的人自己判对错 ——
流程和翻译题一模一样: 写答案 → 判对错 → 判完才展开参考答案对照; 填空题也可以在
`# 设置` 里开成**自动判分**, 见下面"填空题自动判分"。

```
练习二（填空题）
1. 计算机能直接执行的程序是 ____。
参考答案：机器语言程序

练习三（名词解释）
1. 数据结构
参考答案：数据元素之间存在的一种或多种特定关系的集合。
```

- 自评时写的是**参考答案**, 不是机判用的标准答案: 对错自己说了算, 判错进错题本
- 题干和参考答案都能用缩进续行 (见上面"折行"); 题干里的 `____` 会渲染成
  填空题那种下划线样式
- 这类题底下**只认 `参考答案：` 行**: 接到别的行会直接报错, 不会被悄悄拼进题干
  (比如把答案写成选择题的 `答案：A`, 报错会告诉你该写 `参考答案：`)

### 填空题自动判分

在 `# 设置` 行里加上 `填空自动判分` (写 `填空题自动判分` 也认), 这个科目的填空题
就**不用自评**了: 练习里输入框变成单行, 只有一个"提交答案"(在里面敲回车也行), 提交后
拿写的和 `参考答案：` 比对, 一样算对, 不一样算错 —— 判完才给"正确答案", 答错照旧进
错题本。操作系统和数据结构都开着; **这个开关是按科目开的**, 没写这句的科目照旧自评。
它只管填空题, **名词解释题不受影响** (默认还是自己判对错; 想让它干脆不用作答,
见下面"解答题 / 看答案的题"里的点名写法), 所以一个科目里两种题可以各走各的。

考试里同一个开关是另一种节奏: 填空卡上**没有"提交答案"按钮**, 也不会当场判, 写的
答案只在交卷时统一比对 (在那之前翻回去还能改)。没写的算"未答", 成绩单上错和未答
分开数, 交卷前会提示还剩几题。

```
# 设置: 不加入模拟考试, 填空自动判分
```

比对前两个字符串都会先归一化, 下面这些差异不算错:

- 大小写: `cpu` = `CPU`
- 空格: 开头、中间、末尾的空格一律不算 (`系统 资源` = `系统资源`)
- 全角半角: `ＣＰＵ` = `CPU`, 全角括号/逗号也一样
- 末尾的句读: `系统资源。` = `系统资源`

除此之外就是逐字比对 —— **答案要写成标准答法**, 别把可选的说法都塞进一行
(自动判分不认"或")。

## 解答题 / 综合计算题 (看答案的题)

这两种题的参考答案是好几段文字, 还夹着列表、表格和代码块, 没法让人自评, 所以
**不让人作答**: 练习里把参考答案直接摊开, 看完点"下一题"就行。不分对错、不计分
(分值一律 0, 满分里不算它们)、也不进错题本。

别的题型也能这么办 —— 在 `# 设置` 行里点名就行 (题型词照下面"题型"那节的表认,
写 `名词解释直接看答案` 或 `名词解释直接给答案` 都行):

```
# 设置: 单选每题 2 分, 填空每题 2 分, 名词解释直接看答案
```

被点名的题型整个变成上面这种"看答案的题": 练习里参考答案直接摊开, 分值归 0,
不进满分也不进错题本, 首页会多一句"另有 N 题看答案"; 既然不用作答, 它们也就**不进
模拟考试**, 考试卡片上对应的勾选框自动不摆 (数据结构的名词解释就是这么配的)。
认不出来的题型词会被忽略, 别的题一个不动。

题干的写法和选择题一样, 参考答案写完 `参考答案：` 之后 (那一行不写内容),
**往下每行一段, 行首缩进两个空格**:

```
练习三（解答题）

1. 说明处理机的内核态和用户态模式, 使用双重模式的好处是什么？
参考答案：
  处理机至少需要两种单独运行模式：用户态和内核态。
  双重模式执行提供了保护手段, 以防止操作系统和用户程序受到错误用户程序的影响。
```

行首那两格是"续行"标记, 不算正文, 所以**代码块整块再多缩两格, 里面的缩进照样留着**。
一行一段, 想分段就换行, 不要在段中间硬折行。行首带下列标记的会渲染成对应样式:

| 行首 | 渲染成 |
| --- | --- |
| `- ` 或 `* ` | 无序列表 |
| `1. ` `2. ` … | 有序列表 |
| `\|` (整行都是表格) | 表格, 第二行写 `\| --- \| --- \|` 当分隔 |
| 上下用 ` ``` ` 围起来 | 代码块 (等宽字体, 不折行) |
| 其它 | 普通段落 |

题干的缩进续行也一样一行一段 (综合计算题那种"先列三个作业、再问三小问"的写法)。

## 题型

分节标题里出现关键词就会识别成对应题型, 都不出现则默认单选题:

| 关键词 | 题型 |
| --- | --- |
| 单选 / 单项选择 | 单选题 |
| 多选 / 多项选择 | 多选题 |
| 判断 | 判断题 |
| 填空 | 填空题 (自评文字题) |
| 名词解释 | 名词解释 (自评文字题, 每题默认 6 分; 也能在设置里点名改成"看答案的题") |
| 阅读 / 完形 | 阅读理解 |
| 单句翻译 | 单句翻译 (三选项) |
| 简答 / 解答 | 解答题 (看答案的题) |
| 综合计算 / 计算题 | 综合计算题 (看答案的题) |

例:`练习四（多选题）`。

> 注意:目前单选题、单句翻译、阅读理解的**选择题**和**翻译题**、填空 / 名词解释、
> 解答 / 综合计算题有完整的答题逻辑; 多选 / 判断只是被标记出来, 还需要补前端实现。

## 想自定义科目名

文件名是英文或者想用别的显示名时, 在 `scripts/build-questions.js` 顶部的
`SUBJECTS` 里显式加一行:

```js
{ id: 'os', name: '操作系统', file: '题库/operating-systems.txt' }
```

`id` 会作为存储键, 定下来后别再改, 否则之前的错题本和成绩会对不上。

## 并进已有科目 (extra)

有的题库不该单独占一个标签页。比如 `阅读理解.txt` 是英语的一个题型, 就在
`SUBJECTS` 的英语那项上加 `extra`:

```js
{
  id: 'english', name: '英语', file: '整理后的题目.txt', writing: '英语作文.txt',
  extra: [{ file: '题库/阅读理解.txt', prefix: 'r' }],
}
```

- 被 `extra` 认领的文件**不会再单独成科目**, 它的分节 / 短文 / 题目 / 题型并进主科目
- `prefix` 是分节 id 的前缀, 用来避开主文件的分节 id (`r1` 和 `lx1` 不会撞)
- 合并后练习设置里就是一个题型一张卡 (`单选题` / `阅读理解` / `单句翻译` / `写作`),
  模拟考试只算单选题 (其余题型走各自的勾选框)
- `extra` 文件不用写 `# 设置` 行, 分值按 `TYPE_RULES` 的题型分值走;
  真写了也只有"翻译每题 N 分"这种**题型内**的设置对它自己生效,
  `不加入模拟考试` 是科目级的, 以主文件为准
- 题目 id 会换成带前缀的 (`lx1-B-3` → `r1-B-3`), 分节 id 同理。改的那一次,
  合并前记下的阅读错题本 / 成绩会对不上号
